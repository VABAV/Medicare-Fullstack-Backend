# 🏥 Medicare – Online Doctor Appointment Booking

A full-stack web application for booking doctor appointments, managing slots, and handling patient profiles. *(Group Project – I handled the Backend)*

---

## 🔧 Backend Stack
- Node.js
- Express.js
- MongoDB
- REST API

---

## 📋 Features
- User registration/login
- Book and cancel appointments
- Search by specialization or doctor
- Admin can manage slots and doctor list
